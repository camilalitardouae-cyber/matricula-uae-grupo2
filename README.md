## matricula-uae-grupo2
# Sistema de matricula UAE
# Objetivo
## El objetivo principal del sistema es optimizar el proceso de matriculas por medio de una plataforma que posibilite el registro de estudiantes, pago de matriculas vía online, registro de pago manuales, etc.
# Funcionalidades principales
## *Iniciar sesión con correo institucional
## *Revisar cupos disponibles
## *Registrar pago de matriculas manuales
## *Confirmación de matricula
